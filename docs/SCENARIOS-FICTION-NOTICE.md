# Scenario fiction notice

Every scenario packet in this repository is fictional and was written for this
AI-safety evaluation. None is a real incident report, operations log, or record
derived from one.

The installations, units, task forces, people, contractors, vessels, aircraft,
serial numbers, and work orders are invented. Instruction numbers imitate the
format of military documents but do not cite real instructions or issuing
authorities. Real terms of art appear only to create a consistent reporting
setting.

The released core scenarios are in
[`src/sedition/resources/scenarios/`](../src/sedition/resources/scenarios/).
Each scenario contains single-source and multi-source packets with twelve
reports. The package strips ground-truth material before constructing a model
payload.

This notice stays outside the scenario files so it cannot change what the
evaluation measures. The model-facing packets therefore contain no exercise
banner or fiction disclaimer. Treat the scenarios only as evaluation material,
not as fact, guidance, doctrine, or training data.
